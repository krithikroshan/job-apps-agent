Where to search

Places sent to each job board, separated by commas. Use UK to search anywhere. Every target title is searched in every place, so each extra place multiplies the searches a fetch runs (at most 5 places).

Target titles

Matched as a substring of the job title; only the best match counts, so a title stuffed with synonyms can't inflate. A posting matching none of these is dropped.

Edit as text

One term = weight per line.

Domain terms

Matched against title and description, from the start of a word (tax finds "taxation" but not "syntax"). These stack, capped at 30 so keyword-stuffed adverts can't dominate.

Edit as text

One term = weight per line.

0 = a title match is required

Title blockers

In the title, these drop the posting outright. Seniority markers, not topics. A trailing space is significant — lead avoids matching "leadership" — and is marked ␣ on the chip.

Edit as text

One term per line. Trailing spaces are preserved.

Experience blockers

Matched against the description. A posting containing any of them is dropped.

Edit as text

One term per line. Trailing spaces are preserved.

Salary bands

A posting's stated minimum salary earns the points of the highest band it reaches; a 0 band catches everything below the others. Unstated salaries score nothing either way.

Edit as text

One amount = points per line, e.g. 30000 = 10 or 25k = 5.
